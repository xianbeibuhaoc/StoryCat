# 作废 —— 归档区，不参与游戏运行

这里放的是 **v1 / v2 / 阿岩版** 的代码和场景。文件名统一加了 `.作废` 后缀，
所以 **Godot 不会解析它们**（扩展名不是 `.gd` / `.tscn`）。

想翻旧实现，把后缀去掉就能看；想恢复某一版，把它移回原来的位置。

> 为什么不直接删：这台机器上没装 git 命令行，删了没法回滚。
> 等 `自检.ps1` 三套全绿、Windows 导出包能跑通之后，整个 `作废/` 可以删掉。
